# Titanium
Titanium is a hobby programming language, it's like rust, but worse. Inspired by [this series](https://www.youtube.com/playlist?list=PLUDlas_Zy_qC7c5tCgTMYq2idyyT241qs) on youtube.

The compiler is written in Rust with the end goal of eventually rewriting it in Titanium (possibly being interoperable with rust crates)
